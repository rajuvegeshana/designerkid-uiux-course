# CV guide content review

Reviewed 8 November 2026 for the beginner-focused Designerkid guide.

## Sources

- [Enhancv: UX designer resume examples](https://enhancv.com/resume-examples/ux-designer/)
- [Hirist: UI/UX designer resume guidance](https://www.hirist.tech/blog/ui-ux-designer-resume-guidance-with-templates/)
- [Nielsen Norman Group: UX students and graduates](https://www.nngroup.com/articles/resumes-ux-students-and-graduates/)
- [Nielsen Norman Group: UX career changers](https://www.nngroup.com/articles/resumes-ux-career-changers/)

## What the guide uses

- Put a working portfolio and contact details at the top.
- Tailor the order and emphasis to a specific role using only relevant, truthful experience.
- Show project or job context, personal contribution, methods, and observed outcomes or learning.
- Keep a readable layout, clear dates, and a simple timeline. Beginners can move relevant projects above unrelated work.
- Keep editable DOCX and text-based PDF copies. Follow each employer's requested submission format and check links and selectable text.
- Use example resumes as inspiration for structure, with no copied names, experience, or metrics.

## Where sources differ

- Hirist suggests a functional format for beginners; Enhancv prefers a hybrid format and discourages a purely functional one; NN/g recommends reverse chronology within experience. The guide therefore recommends a simple dated layout with relevant projects placed prominently rather than prescribing a named format.
- Hirist suggests PDF as the application file; NN/g explains reasons to keep both DOCX and PDF. The guide tells students to follow the application instruction and verify the final file.
- Some sample resumes contain large numerical results. These are examples, not evidence of what a student achieved. The guide requires every number to be explainable and offers qualitative outcomes for class projects.

## Deliberately omitted

Salary ranges, claims about the best weekday to apply, ATS success guarantees, arbitrary keyword density, and sample performance percentages were not carried into the guide. They are not necessary to help a beginner write a clear, credible CV.
